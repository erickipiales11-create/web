# 🏥 Sistema Clínico - Gestión de Farmacias

## 📋 Descripción del Proyecto

Sistema web para la gestión de farmacias y medicamentos, desarrollado como parte de un proyecto académico para la asignatura de Desarrollo de Aplicaciones Web.

### 🎯 Objetivos

- Desarrollar una aplicación web completa con frontend y backend
- Implementar operaciones CRUD mediante APIs RESTful
- Consumir servicios web desde el frontend
- Gestionar farmacias y medicamentos de manera eficiente

---

## 🚀 Tecnologías Utilizadas

### Backend
- **Node.js** - Entorno de ejecución
- **Express.js** - Framework web
- **PostgreSQL** - Base de datos relacional
- **Sequelize** - ORM para Node.js
- **JWT** - Autenticación
- **Bcrypt** - Encriptación de contraseñas

### Frontend
- **HTML5** - Estructura
- **CSS3** - Estilos y diseño responsive
- **JavaScript (ES Modules)** - Lógica y consumo de API
- **Fetch API** - Peticiones HTTP

### Herramientas
- **Git** - Control de versiones
- **Postman** - Pruebas de API
- **pgAdmin** - Gestión de base de datos
